# GlassMate — своё приложение для очков MT5 Ultra

Это замена приложения AIBuds для Android. Что оно умеет:

- **Своя ИИ-модель.** Claude или любая модель с OpenAI-совместимым API: OpenAI, OpenRouter, Gemini, локальные LM Studio и Ollama.
- **ИИ видит то же, что вы.** К вопросу прикладывается снимок с камеры очков. Он приходит прямо по Bluetooth, Wi-Fi не нужен.
- **Голос.** Вопрос слушается микрофоном очков, ответ звучит в динамиках очков.
- **Своё управление.** Каждому касанию дужки можно назначить действие, а касания можно сделать запуском ИИ.
- **Камера.** Фото и видео на память очков, импорт файлов в галерею телефона по Wi-Fi.

## Как собрать APK

### Вариант 1: GitHub, без установки программ
1. Создайте пустой репозиторий на github.com и загрузите в него содержимое этой папки (Add file → Upload files).
2. Откройте вкладку **Actions**. Сборка «Build APK» запустится сама и займёт около 5 минут.
3. Откройте завершённую сборку. Внизу, в разделе **Artifacts**, скачайте `GlassMate-apk`. Внутри zip лежит `app-debug.apk`.
4. Установите APK на телефон. Samsung попросит разрешить установку из этого источника.

### Вариант 2: Android Studio на компьютере
1. В Android Studio выберите Open и укажите эту папку. Дождитесь синхронизации Gradle.
2. Подключите телефон по USB с включённой отладкой и нажмите Run.

## Первый запуск
1. **Закройте AIBuds:** «Настройки → Приложения → AIBuds → Остановить». Очки держат только одно управляющее соединение.
2. Откройте GlassMate и дайте все разрешения: устройства поблизости, микрофон, уведомления.
3. Выберите очки в списке и нажмите **Подключить**. Очки должны быть сопряжены в настройках Bluetooth телефона.
4. В разделе **Модель ИИ** выберите провайдера, вставьте API-ключ и нажмите **Сохранить настройки**.
5. Проверьте работу: **ИИ-снимок** покажет кадр с камеры очков, **Что я вижу?** опишет его голосом.

## Как запускать ИИ с очков
Очки передают касания телефону как медиакнопки. GlassMate их перехватывает:

| Действие очков | Что делает GlassMate |
|---|---|
| Плей / пауза | Вопрос голосом со снимком |
| Следующий трек | «Что я вижу?» |
| Предыдущий трек | Прервать ответ |

В разделе **Кнопки на очках** нажмите «Считать с очков», назначьте нужным жестам эти действия и нажмите «Записать на очки».

Важно: Android отдаёт медиакнопки приложению, которое последним играло звук. Если вы включили музыку в другом приложении, касания уйдут туда. Чтобы вернуть их, переподключите очки или снова нажмите «Сохранить настройки».

Альтернатива: назначьте жесту «Голосовой ассистент». Тогда телефон откроет голосовой ввод, и в качестве приложения для голосовых команд можно выбрать «GlassMate: спросить ИИ».

## Что пока не проверено на ваших очках
- Сигнал собственной ИИ-кнопки очков (команда `0xB0`). По умолчанию он не запускает ИИ. Нажмите эту кнопку и посмотрите журнал: если там появилась строка «сигнал ИИ-кнопки», включите галочку «Запускать по сигналу ИИ-кнопки очков».
- Батарея показывается как сырые байты, формат ещё не расшифрован.
- Если что-то не работает, нажмите «Скопировать журнал» и пришлите текст.

## Протокол (кратко)
Подробно он описан в комментариях `app/src/main/java/app/glassmate/glasses/AbMate.kt`.

- Связь по Bluetooth SPP (RFCOMM, UUID `00001101-…`). Протокол ABMate от Bluetrum.
- Кадр: `[seq 0..15][команда][тип 1/2/3][фрагмент][длина][данные ≤15 байт]`.
- `0xE1 [1]`: ИИ-снимок. JPEG приходит уведомлениями `0xE3 [статус][данные]`, где статус 1 = будет ещё, 0 = последний кусок.
- `0xE1 [0]`: фото на память очков. `0xE4`: старт видео. `0xE2`: стоп и выключение камеры.
- `0x22 [жест][1][действие]`: настройка кнопок. Жесты 1–8, действия 0–9.
- `0x27 [тип][0]…`: запрос информации (ответ TLV). Тип 5 = настройки кнопок.
- `0xF0 [время, int32 LE][смещение пояса в минутах, int16 LE]`: установка часов.
- `0xE6` + `0xE7`: точка доступа `AiGlass<MAC>` (пароль `12345678`) и файловый сервер. Список файлов лежит в `media.config`.
